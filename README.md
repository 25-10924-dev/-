# 일본 여행 회화 도우미

일본 여행 중 자주 쓰는 문장을 상황별로 확인할 수 있는 간단한 웹 앱입니다.

## 기능
- 카테고리별 회화 보기 (인사/교통/식당/쇼핑/긴급/편의)
- 한글, 일본어, 로마자 기준 검색
- 즐겨찾기 저장 (브라우저 localStorage)
- 일본어 문장 복사 버튼

## 실행 방법
정적 파일만으로 동작합니다.

1. `index.html`을 브라우저에서 엽니다.
2. 검색어와 카테고리를 활용해 원하는 문장을 찾습니다.

## 파일 구성
- `index.html`: UI 구조
- `styles.css`: 화면 스타일
- `app.js`: 회화 데이터 및 필터/즐겨찾기/복사 로직
